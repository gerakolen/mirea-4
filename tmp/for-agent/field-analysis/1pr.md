1 ПРАКТИЧЕСКАЯ РАБОТА (АНАЛИЗ
ПРЕДМЕТНОЙ ОБЛАСТИ И ПОСТАНОВКА ЗАДАЧИ)
1.1 Цель работы
Целью практической работы является формирование исходного
представления о проектируемой системе управления данными посредством
анализа выбранной предметной области, определения назначения системы,
категорий пользователей, основных функций, информационных объектов и
ограничений.
1.2 Задачи работы
В процессе выполнения практической работы необходимо:
• выбрать предметную область, в рамках которой будет выполняться
сквозной проект;
• определить назначение проектируемой системы;
• определить основные категории пользователей системы;
• установить роли пользователей и границы их ответственности;
• выделить основные функции проектируемой системы;
• определить основные группы данных, подлежащие хранению и
обработке;
• сформулировать основные бизнес-правила и ограничения предметной
области;
• определить предполагаемые границы проектируемой системы;
• подготовить исходные материалы для последующего формирования
требований и разработки технического задания.
1.3 Теоретические сведения
Предметная область представляет собой часть реального или условного
объекта деятельности, информация о котором должна быть представлена,
сохранена, обработана и использована средствами проектируемой системы.
До начала непосредственного проектирования базы данных необходимо
определить назначение разрабатываемой системы и установить, какие
информационные и пользовательские процессы она должна обеспечивать.
При анализе предметной области необходимо определить:
• объекты, сведения о которых подлежат хранению;
• участников информационных процессов;
• действия, выполняемые участниками;
• ограничения и правила, регулирующие выполнение операций;
• информационные взаимосвязи между объектами;
• результаты, которые должны быть получены в процессе эксплуатации
системы.
При выполнении анализа следует избегать преждевременного перехода к
физической структуре базы данных. На данном этапе необходимо определить
содержание предметной области, а не конкретное количество таблиц и полей
будущей базы данных.
Проектируемая система должна представлять собой не совокупность
независимых справочников, а средство поддержки взаимосвязанных процессов
работы с данными.
1.4 Задание
Необходимо выбрать предметную область и выполнить её
предварительный анализ.
Результат анализа должен позволять сформировать однозначное
представление о том:
• для решения какой задачи создаётся система;
• кто является её пользователем;
• какие действия пользователи должны выполнять;
• какие данные необходимы для выполнения этих действий;
• какие правила и ограничения должны соблюдаться при работе
системы.
В рамках практической работы необходимо подготовить
структурированное описание проектируемой системы.
