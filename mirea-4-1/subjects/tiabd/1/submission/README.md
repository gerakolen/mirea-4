# Практическая работа № 1 — комплект сдачи

## Состав

1. `01_FiresRu.ipynb` — выполненные учебные блоки по предоставленному `FiresRu.csv`.
2. `02_Own_Dataset.ipynb` — самостоятельный анализ UCI Bike Sharing Dataset.
3. `03_Control_Questions.md` — ответы на 12 контрольных вопросов.
4. `data/bike_sharing_hour.csv` — исходный собственный датасет.
5. `data/SOURCE.md` и `data/UCI_Readme.txt` — источник, лицензия и словарь данных.
6. `output/fires/` и `output/own/` — очищенные CSV, JSON Lines и Parquet.

Оба notebook сохранены с результатами выполнения и графиками, выполняются последовательно от чистого ядра и не содержат ошибок.

## Окружение

- Python 3.12.2
- pandas 3.0.1
- NumPy 2.4.2
- Matplotlib 3.10.8
- pyarrow 25.0.1

Локальное окружение находится в соседнем каталоге `.venv`. Для интерактивного запуска из каталога `subjects/tiabd/1`:

```bash
source .venv/bin/activate
export JUPYTER_PATH="$PWD/.venv/share/jupyter"
jupyter notebook submission
```

В Jupyter следует выбрать ядро `Python (TIABD PR1)` и выполнить `Restart Kernel and Run All Cells`.

## Краткий итог

В учебной части подтверждены форма `FiresRu.csv` `(26681, 9)`, отсутствие пропусков/дубликатов, дисбаланс типов событий и слабые линейные связи погодных признаков. Подготовлены четыре графика и экспорты трёх форматов.

В самостоятельной части исследованы 17 379 почасовых наблюдений UCI Bike Sharing за 2011-2012 годы. Выполнены паспорт, диагностика, типизация, фильтр, группировки, корреляции, IQR, четыре графика с временным рядом и round-trip экспортов. Зафиксировано важное ограничение: внутри временного диапазона отсутствуют 165 часов.
