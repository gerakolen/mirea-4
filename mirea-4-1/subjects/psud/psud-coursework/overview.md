# Курсовая работа по ПСУД

## Тема

**«Разработка системы управления данными валютного рынка на основе данных T-Invest, Московской биржи и Банка России»**.

Краткое название: **«Система управления данными валютного рынка»**.

## Предметная область

Курсовая работа посвящена централизованному управлению данными валютного рынка на примере CNY/RUB. Система объединяет биржевые котировки, обезличенные сделки, официальные курсы и связанные сведения из нескольких источников.

Проект связан с Т-Банком через T-Invest API и представляет собой самостоятельный учебный прототип без торговых операций и персональных данных.

## Объект исследования

Процессы сбора, хранения, обработки и использования данных валютного рынка.

## Предмет исследования

Методы и средства проектирования системы управления валютными данными: моделирование, реляционное хранение, обеспечение целостности, интеграция источников и предоставление аналитической информации.

## Цель

Спроектировать и частично реализовать работающую систему, которая получает реальные валютные данные, сохраняет их в согласованной структуре, контролирует качество и предоставляет результаты пользователю.

## Основные задачи

- проанализировать предметную область и существующие решения;
- сформировать требования и архитектуру системы;
- смоделировать бизнес-процессы и структуру данных;
- реализовать реляционную базу и средства управления данными;
- организовать получение данных из нескольких источников;
- обеспечить целостность, повторяемость загрузок и контроль качества;
- создать аналитические представления и пользовательский интерфейс;
- проверить соответствие реализации требованиям.

## Общая структура системы

Система включает загрузку данных T-Invest, MOEX и Банка России, реляционное хранилище PostgreSQL, аналитические преобразования и интерфейс для просмотра показателей. Основное внимание уделяется модели данных, ограничениям целостности, серверной логике и пользовательским сценариям.

## Источники

- [T-Invest API](https://developer.tbank.ru/invest/api/market-data-service-get-candles);
- [исторические данные T-Invest](https://developer.tbank.ru/invest/services/history-md/head-history-md);
- [MOEX ISS](https://iss.moex.com/iss/reference/);
- [Банк России](https://www.cbr.ru/development/SXML/).

Доступность достаточного объёма реальных исторических данных CNY/RUB была подтверждена практическими запросами. Синтетические данные не требуются.

## Стек

- PostgreSQL — основное хранилище и серверная логика;
- Python — интеграция с внешними источниками;
- SQL-миграции — воспроизводимое создание базы;
- dbt Core — аналитические преобразования, документация и проверки;
- Metabase — пользовательский аналитический интерфейс;
- pytest — тестирование загрузчиков и правил;
- Docker Compose — локальное развёртывание.

Полноценный оркестратор, ClickHouse и Spark в курсовую не входят: они относятся к более крупному проекту по ПАС.

## Результат

Итогом станет работающий прототип реляционной системы управления валютными данными, объединяющий базу, загрузку, контроль качества и аналитический интерфейс. В пояснительной записке будут представлены анализ, требования, BPMN и UML, модели базы, реализация и результаты проверки.

## Связь с другими работами

Курсовая объединяет результаты практических работ в законченную систему. Её предметная модель, загрузчики, правила качества и аналитические определения затем переиспользуются в платформе по ПАС.
